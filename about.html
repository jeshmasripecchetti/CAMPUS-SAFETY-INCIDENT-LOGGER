About Our Project

Project Overview

Campus Safety Incident Logger is a web-based application that enables students, faculty, and campus staff to report safety-related incidents quickly and securely. The system improves communication between users and administrators, helping create a safer campus environment.

Project Objectives

  • Improve campus safety.
  • Enable online incident reporting.
  • Reduce response time.
  • Maintain secure incident records.
  • Provide real-time analytics.
