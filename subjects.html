Relevant Subjects

Programming for Problem Solving (Python)

Python is used to develop the application logic, validate incident details, process user inputs, and manage the reporting system. It helps automate data processing and supports future integration with databases and analytics.

Engineering Mathematics

Mathematics is useful for analyzing incident records, generating statistics, calculating trends, and creating graphical reports that help administrators understand campus safety patterns.

English Communication Skills

Effective communication helps users write clear incident reports and enables the system to display professional messages, notifications, and documentation for administrators.

Basic Electrical & Electronics Engineering

Knowledge of sensors, CCTV cameras, alarms, and electronic security devices helps understand how safety monitoring systems work in a smart campus environment.

Engineering Graphics

Engineering Graphics helps in planning the user interface, dashboard layout, navigation flow, and visual representation of the project through diagrams and workflow models.

Environmental Science (Relevant Concept)

Environmental awareness contributes to creating a safe and secure campus by promoting responsible behavior, emergency preparedness, and sustainable safety practices.
